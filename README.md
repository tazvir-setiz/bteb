# ربات انتقال خودکار پیام از بله به ایتا (Bale to Eitaa Forwarder Bot)

ربات هوشمند و کامل برای فوروارد خودکار و آنی انواع پیام‌ها (متن، عکس، ویدیو، سند/فایل، صوت، ویس و گیف) از کانال **بله** به کانال **ایتا** همراه با **داشبورد مدیریتی تعاملی درون پیام‌رسان بله**.

---

## 🌟 ویژگی‌های کلیدی

- 🎛 **داشبورد تعاملی در بله:**
  - تنظیم آسان کلید API ایتا یار (`Eitaayar API Token`) مستقیماً از طریق چت بله
  - تنظیم کانال مقصد در ایتا (`chat_id` یا آیدی بدون `@`)
  - تنظیم کانال مبدا در بله (شناسه عددی مانند `-100...` یا آیدی عمومی `@channel`)
  - دکمه تغییر وضعیت آنی فوروارد (فعال / توقف موقت)
  - دکمه تست اتصال به ایتا یار (`getMe`) جهت اطمینان از صحت توکن
  - مشاهده آمار تفصیلی پیام‌های ارسالی، پیام‌های ناموفق و زمان آخرین ارسال
  - راهنمای گام‌به‌گام راه‌اندازی درون ربات
- 🔄 **پشتیبانی کامل از انواع مدیا و پیام:**
  - پیام‌های متنی (Text)
  - تصاویر و عکس‌ها با کیفیت بالا همراه با کپشن (Photo)
  - فایل‌ها و اسناد همراه با کپشن (Documents)
  - ویدیوها همراه با کپشن (Videos)
  - فایل‌های صوتی و ویس (Audio & Voice)
  - تصاویر متحرک گیف (Animations / GIFs با فرمت استاندارد ایتا یار)
- 💾 **ذخیره‌سازی پایدار تنظیمات (Persistence):**
  - تنظیمات اعمال‌شده در داشبورد بلافاصله در فایل دائمی ذخیره شده و پس از ری‌استارت ربات باقی می‌مانند.
- 🔒 **امنیت و احراز هویت ادمین:**
  - فقط ادمین‌های مجاز به داشبورد دسترسی دارند.
  - در صورت مشخص نکردن ادمین در `.env`، اولین کاربری که به ربات `/start` بزند به عنوان ادمین ثبت می‌شود.
- ⚡️ **معماری ماژولار و تست‌شده:**
  - پیاده‌سازی بر پایه `httpx` و `asyncio`
  - پوشش کامل تست‌های واحد و یکپارچه‌سازی با `pytest` (۲۵ تست موفق)

## 🐳 اجرای سریع با داکر (Docker & Docker Compose)

اگر روی سرور خود داکر دارید، می‌توانید ربات را تنها با دو دستور اجرا کنید:

```bash
# ۱. تنظیم توکن در فایل .env
cp .env.example .env

# ۲. اجرای کانتینر در پس‌زمینه
docker compose up -d --build
```

مشاهده لاگ‌های کانتینر داکر:
```bash
docker compose logs -f
```

## 🚀 راهنمای نصب و راه‌اندازی

### ۱. پیش‌نیازها
- پایتون نسخه 3.9 یا بالاتر (تست شده روی Python 3.15)
- یک ربات بله (از طریق بازوی `BotFather` در بله ساخته شده باشد)
- یک حساب کاربری و کلید API در [ایتا یار (eitaayar.ir)](https://eitaayar.ir)

### ۲. نصب وابستگی‌ها
در ترمینال، دستور زیر را اجرا کنید:
```bash
pip install -r requirements.txt
```

### ۳. تنظیم فایل پیکربندی اولیه
فایل `.env.example` را کپی کرده و به نام `.env` ذخیره کنید:
```bash
cp .env.example .env
```
محتوای `.env`:
```env
# توکن ربات بله (الزامی)
BALE_BOT_TOKEN=123456789:ABCdefGHI...

# شناسه عددی ادمین در بله (اختیاری؛ در صورت خالی بودن اولین نفر که /start بزند ادمین می‌شود)
ADMIN_USER_ID=

# کلید API ایتا یار (می‌توانید بعداً در داشبورد بله نیز وارد کنید)
EITAA_API_TOKEN=

# شناسه کانال ایتا (می‌توانید بعداً در داشبورد بله نیز وارد کنید)
EITAA_CHANNEL_ID=

# شناسه کانال بله (می‌توانید بعداً در داشبورد بله نیز وارد کنید)
BALE_CHANNEL_ID=
```

## 📱 آموزش استفاده از داشبورد بله

1. پس از اجرای ربات، به صفحه گفتگوی خصوصی با ربات خود در بله بروید.
2. دستور `/start` یا `/dashboard` را ارسال کنید.
3. منوی مدیریت با دکمه‌های شیشه‌ای (Inline Keyboard) نمایش داده می‌شود:
   - **⏸ توقف / ▶️ فعال‌سازی ارسال:** سوییچ روشن/خاموش کردن انتقال پیام‌ها.
   - **🔑 تنظیم توکن ایتا یار:** دکمه را لمس کرده و سپس توکن دریافتی از ایتا یار را بفرستید.
   - **📢 تنظیم کانال ایتا:** شناسه یکتا یا آیدی کانال ایتا (بدون `@`) را ارسال نمایید.
   - **📥 تنظیم کانال بله:** شناسه عددی یا آیدی عمومی کانال بله خود را بفرستید.
   - **🔍 تست اتصال ایتا:** متد `getMe` ایتا یار را فراخوانی کرده و سلامت توکن و نام بات را چک می‌کند.
   - **📊 گزارش و آمار:** نمایش تعداد پیام‌های موفق، ناموفق، آخرین زمان ارسال و امکان صفر کردن آمار.
   - **❓ راهنمای راه‌اندازی:** راهنمای کوتاه در مورد نحوه ادمین کردن بات در کانال‌ها.

## 📌 مراحل آماده‌سازی کانال‌ها

### در بله:
1. ربات خود را به کانال مبدا بله اضافه کنید.
2. به ربات در کانال دسترسی مدیر (Admin) بدهید.
3. آیدی عمومی کانال (مانند `@my_bale_channel`) یا شناسه عددی آن را در داشبورد ثبت کنید.

### در ایتا:
1. طبق آموزش‌های پنل ایتا یار (`eitaayar.ir`)، بات ایتایار را به عنوان مدیر در کانال مقصد ایتا با دسترسی ارسال پیام عضو کنید.
2. نام کاربری کانال مقصد در ایتا (یا شناسه یکتای کانال) را در داشبورد ثبت کنید.

اکنون می‌توانید در بله با ربات چت کنید و تنظیمات را انجام دهید. هر پیامی در کانال مبدا بله منتشر شود، بی‌درنگ به کانال مقصد در ایتا منتقل خواهد شد!
