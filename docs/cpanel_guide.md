# راهنمای استقرار و اجرای ربات در هاست cPanel

هاست‌های لینوکسی اشتراکی مجهز به cPanel یکی از رایج‌ترین و اقتصادی‌ترین روش‌های میزبانی وب در ایران هستند. از آنجایی که این ربات به صورت پس‌زمینه دائمی (Daemon / Long Polling) کار می‌کند، این راهنما به شما یاد می‌دهد چگونه بدون دردسر ربات را در cPanel راه‌اندازی و به صورت ۲۴ ساعته فعال نگه دارید.

## ۱. پیش‌نیازهای cPanel
- دسترسی به کنترل پنل cPanel.
- فعال بودن دسترسی **Terminal** یا **SSH** در هاست (اگر فعال نیست، به پشتیبانی هاست تیکت بزنید تا دسترسی ترمینال را فعال کنند).
- پایتون نسخه 3.9 به بالا.

---

## روش ۱: بارگذاری فایل‌ها در cPanel

1. وارد cPanel شوید و به بخش **File Manager** بروید.
2. در پوشه اصلی حساب خود (مثلاً `/home/username/`) یک پوشه جدید به نام `bteb` بسازید (مسیر: `/home/username/bteb`).
3. تمام فایل‌های این پروژه را درون این پوشه بارگذاری (Upload) کنید:
   - `bot.py`
   - `bale_client.py`
   - `eitaa_client.py`
   - `forwarder.py`
   - `dashboard.py`
   - `config.py`
   - `requirements.txt`
   - `.env.example`

---

## روش ۲: راه‌اندازی محیط پایتون از طریق Terminal

1. در cPanel به بخش **Advanced** رفته و گزینه **Terminal** را باز کنید.
2. وارد پوشه پروژه شوید:
   ```bash
   cd ~/bteb
   ```
3. ساخت محیط مجازی (Virtual Environment) پایتون:
   ```bash
   python3 -m venv venv
   ```
   یا اگر پایتون با نسخه خاصی نصب است (مثلاً python3.11):
   ```bash
   python3.11 -m venv venv
   ```
4. فعال‌سازی Virtualenv:
   ```bash
   source venv/bin/activate
   ```
5. ارتقای pip و نصب وابستگی‌های ربات:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

## تنظیم متغیرهای محیطی (.env)

در ترمینال یا از طریق File Manager یک فایل به نام `.env` بسازید:
```bash
cp .env.example .env
nano .env
```
مقدار توکن بله را قرار دهید:
```env
BALE_BOT_TOKEN=123456789:AAHk...
DATA_STORAGE_PATH=bot_data.json
```
*(کلید ایتا یار و آیدی کانال‌ها را می‌توانید بعداً از داشبورد بله تنظیم کنید).*

## فعال نگه داشتن دائمی ربات با Watchdog Cron Job (بسیار مهم)

در هاست‌های اشتراکی cPanel، به دلیل محدودیت‌های سیستم ابری (CloudLinux LVE Manager) یا ریبوت سرور، ممکن است پروسه‌های در حال اجرا پس از چند ساعت متوقف شوند.  
بهترین و مطمئن‌ترین روش، ایجاد یک اسکریپت دیده‌بان (Watchdog) به کمک **Cron Jobs** در cPanel است که هر چند دقیقه یک‌بار بررسی کند اگر ربات متوقف شده باشد، آن را مجدداً بالا بیاورد.

### مرحله ۱: ساخت فایل دیده‌بان `run_watchdog.sh`

در ترمینال cPanel دستور زیر را وارد کنید:
```bash
nano ~/bteb/run_watchdog.sh
```
کد زیر را درون آن قرار دهید (نام `your_user` را با نام کاربری cPanel خود جایگزین کنید):

```bash
#!/bin/bash
PROJECT_DIR="$HOME/bteb"
cd "$PROJECT_DIR" || exit 1

# بررسی آیا اسکریپت bot.py در حال اجراست؟
if ! pgrep -f "python.*bot.py" > /dev/null; then
    echo "$(date '+%Y-%m-%d %H:%M:%S') - Bot was offline. Restarting..." >> "$PROJECT_DIR/watchdog.log"
    source "$PROJECT_DIR/venv/bin/activate"
    nohup python bot.py >> "$PROJECT_DIR/bot.log" 2>&1 &
fi
```

مجوز اجرایی دادن به فایل:
```bash
chmod +x ~/bteb/run_watchdog.sh
```

### مرحله ۲: تنظیم Cron Job در cPanel

1. در cPanel به بخش **Advanced** > **Cron Jobs** بروید.
2. در بخش **Add New Cron Job**:
   - در قسمت تنظیم زمان (Common Settings)، گزینه **Once Per Minute (* * * * *)** یا **Every 5 Minutes (*/5 * * * *)** را انتخاب کنید.
   - در کادر **Command**، دستور زیر را وارد نمایید:
     ```bash
     /bin/bash /home/your_user/bteb/run_watchdog.sh >/dev/null 2>&1
     ```
   *(دقت کنید به جای `your_user` نام کاربری هاست خود را قرار دهید)*
3. روی دکمه **Add New Cron Job** کلیک کنید.

از این لحظه، هاست به صورت خودکار ربات شما را اجرا کرده و اگر سرور ری‌استارت شود یا پروسه بسته شود، ظرف ۱ تا ۵ دقیقه به طور خودکار آن را دوباره روشن می‌کند.

## مدیریت و مشاهده لاگ‌های ربات

برای مشاهده فعالیت‌ها و پیام‌های پردازش‌شده در ترمینال:
```bash
tail -f ~/bteb/bot.log
```
برای متوقف کردن دستی ربات:
```bash
pkill -f "python.*bot.py"
```

## نکات و محدودیت‌های هاست اشتراکی cPanel

1. **دسترسی به پورت‌های خروجی (Outbound HTTPS):**  
   ربات برای ارتباط با `tapi.bale.ai` و `eitaayar.ir` از پورت استاندارد `443` استفاده می‌کند که در تقریباً تمامی هاست‌ها باز است.
2. **محدودیت حجم رم (RAM Usage):**  
   این ربات به علت استفاده از معماری بهینه پایتون و بدون وب‌سرور سنگین، کمتر از ۴۰ مگابایت رم مصرف می‌کند و به هیچ وجه سقف رم هاست اشتراکی را پر نخواهد کرد.
3. **فایل ذخیره‌سازی داده‌ها (`bot_data.json`):**  
   این فایل حاوی تنظیمات انجام‌شده در داشبورد بله است؛ از حذف دستی آن خودداری نمایید.
