# راهنمای استقرار و دیپلوی ربات در Railway (railway.com)

پلتفرم ابری **Railway** یکی از مدرن‌ترین و پایدارترین ارائه‌دهندگان سرویس ابری (PaaS) در جهان است که برای اجرای دائمی ربات‌های پایتونی با داکر به شدت توصیه می‌شود. با استفاده از داکرفایل موجود در پروژه، ربات شما بدون کوچک‌ترین قطعی به صورت ۲۴ ساعته فعال خواهد بود.

## ۱. پیش‌نیازها
- یک حساب کاربری رایگان در [Railway.com](https://railway.com) (یا railway.app).
- یک حساب در [GitHub](https://github.com).
- توکن ربات بله (`BALE_BOT_TOKEN`).

---

## مرحله ۱: آپلود کد در گیت‌هاب (GitHub)

1. در گیت‌هاب یک ریپازیتوری جدید (عمومی یا خصوصی) ایجاد کنید (مثلاً `bale-to-eitaa-bot`).
2. پروژه خود را به گیت‌هاب پوش (Push) کنید:
   ```bash
   git remote add origin https://github.com/your-username/bale-to-eitaa-bot.git
   git branch -M main
   git push -u origin main
   ```

---

## مرحله ۲: ایجاد پروژه جدید در Railway

1. وارد داشبورد خود در **Railway** شوید.
2. روی دکمه **"+ New Project"** کلیک کنید.
3. گزینه **"Deploy from GitHub repo"** را انتخاب کنید.
4. ریپازیتوری `bale-to-eitaa-bot` را که در مرحله قبل ساختید انتخاب کنید.
5. سیستم Railway به طور خودکار فایل `Dockerfile` موجود در ریشه پروژه را شناسایی می‌کند و فرآیند ساخت ایمیج را آغاز می‌نماید.

---

## مرحله ۳: تنظیم متغیرهای محیطی (Variables)

1. پس از انتخاب ریپازیتوری، وارد تب **Variables** در سرویس ایجادشده شوید.
2. متغیرهای زیر را با کلیک روی **"New Variable"** اضافه کنید:

| نام متغیر | مقدار نمونه | توضیحات |
| :--- | :--- | :--- |
| `BALE_BOT_TOKEN` | `123456789:AAHk...` | توکن دریافتی از BotFather در بله (الزامی) |
| `DATA_STORAGE_PATH` | `/app/data/bot_data.json` | مسیر ذخیره فایل دیتای دائمی (الزامی) |
| `ADMIN_USER_ID` | `12345678` | شناسه عددی ادمین در بله (اختیاری) |

> **نکته:** کلید API ایتا یار و آیدی کانال‌ها نیازی نیست حتماً در این بخش وارد شوند؛ می‌توانید بعداً از طریق داشبورد بله آن‌ها را با یک کلیک تنظیم کنید.

---

## مرحله ۴: افزودن دیسک دائمی (Persistent Volume) - بسیار مهم

کانتینرهای ابری داکر به صورت پیش‌فرض موقتی (Ephemeral) هستند؛ یعنی هر بار که کد جدیدی پوش کنید یا پروژه ری‌استارت شود، فایل‌های درون کانتینر ریست می‌شوند.  
برای این که تنظیمات شما (توکن ایتا، کانال‌ها و آمار) که از داشبورد بله تنظیم می‌کنید پایدار بمانند:

1. در داشبورد Railway، روی علامت **"+ New"** در گوشه پروژه کلیک کنید.
2. گزینه **"Volume"** را انتخاب نمایید.
3. در تنظیمات Volume:
   - در بخش **Mount Path** مقدار زیر را تایپ کنید:
     ```text
     /app/data
     ```
   - این Volume را به سرویس ربات خود متصل (Attach) نمایید.
4. روی **Save Changes** کلیک کنید.

اکنون تمام تنظیمات شما درون فایل `/app/data/bot_data.json` بر روی این دیسک ذخیره می‌شود و حتی با بازسازی کانتینر یا دیپلوی‌های بعدی هرگز پاک نخواهد شد!

---

## مرحله ۵: بررسی لاگ‌ها و تایید سلامت دیپلوی

1. وارد تب **Deployments** یا **View Logs** شوید.
2. پس از پایان ساخت موفق (Build Finished)، باید لاگ‌هایی مشابه زیر مشاهده کنید:

```text
2026-11-17 19:15:01 [INFO] BotRunner: Starting Bale-to-Eitaa Forwarder Bot...
2026-11-17 19:15:02 [INFO] BotRunner: Connected to Bale as @MyForwarderBot
2026-11-17 19:15:02 [INFO] BotRunner: Bot is active and polling updates...
```

اگر این پیام‌ها را دیدید، تبریک می‌گوییم! ربات شما با موفقیت روی سرور ابری Railway به صورت پایدار و ۲۴ ساعته فعال شده است.

---

## نکات به‌روزرسانی خودکار (Auto Deploy)

پلتفرم Railway مجهز به CI/CD خودکار است. هر زمان که تغییری در کدها داده و به شاخه اصلی ریپازیتوری خود در GitHub پوش (Push) کنید، Railway به صورت خودکار نسخه جدید را بیلد کرده و بدون وقفه در کارکرد ربات، آن را بروزرسانی می‌کند.
